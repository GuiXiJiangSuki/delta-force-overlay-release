## 这是什么

一个给 OBS 用的浏览器源 Overlay。挂在直播间角落，实时显示「上把带出多少」「今日累计带出多少」「今日净收益」「出了几张红卡」。

数据来自 WeGame 战绩接口，走的是你自己的账号，不经过任何第三方服务器。

同时附带一套**账号管理 + 数据查询**面板：每日密码、卡战备配装、假账排行、交易行、改枪码、改枪模拟、战绩统计等。

## 核心功能

### 一、OBS 直播间 Overlay（主打）

透明背景的网页，加进 OBS 浏览器源即可。

| 显示内容 | 说明 |
|---|---|
| 上把带出 | 最近一局的带出哈夫币价值 |
| 今日累计带出 | 当天所有对局的带出总和 |
| 今日净收益 | 官方口径的净收益（可轮播） |
| 出货分类 | 红 / 卡 / 金 等物品明细，带图标滚动展示 |
| 撤离状态 | 撤离成功 / 撤离失败 |
| 角色头像与名字 | 当前选中的角色 |

**OBS 设置**：浏览器源尺寸填 **540 × 340**，背景透明，位置贴左上角。

可调项：
- **刷新间隔** — 数据多久拉一次
- **统计局数** — 今日累计取最近多少局
- **轮播「今日净收益」** — 开关 + 切换间隔
- **出货滚动速度** — 物品列表滚动快慢

### 二、账号管理

- **扫码登录 WeGame** — 不用输密码，扫一次即可
- **多账号保存与切换** — 已登录账号点一下即切，无需重新扫码
- **登录态自动续期** — 每 30 分钟自动检查并续期，票龄超 2 小时强制续期
- **角色选择** — 同一账号下多个角色可切换（槽位 / 等级 / 哈夫币余额一目了然）

### 三、每日密码

- 今日各地图**每日密码**，每天 0 点自动更新
- 点击地图卡片可查看**藏密码位置截图**，不用自己找
- 覆盖：零号大坝、长弓溪谷、巴克什、航天基地、潮汐监狱、AZ3 等

### 四、卡战备（配装方案）

- 实时**配装方案**，自动算「凑战备」该买什么
- 支持 **kk日报 / 小黑盒** 双数据源切换
- 显示总花费、最终战备值、战备套价
- 每件装备标注市场价与「省多少」
- 战备活动时间：每周五 12:00 ~ 周日 23:59

### 五、假账排行 / 交易行查询

**假账排行**
- 各物品「市场价 vs 战备价」差价排行
- 战备值比市场价高 = 划算，直接看能省多少
- 分武器 / 配件 / 头盔 / 护甲 / 胸挂 / 背包 分类

**交易行查询**
- 交易行**趋势**图
- **价格预测**
- **物品数据库**检索
- 特勤处利润排行（哪些制作最赚钱）

### 六、改枪码 / 改枪模拟

**改枪码**
- 云码库热门改枪码（烽火地带），按浏览量排序
- 点「复制」后在游戏内改枪界面粘贴即可应用

**改枪模拟**
- 自由搭配配件，实时预览**属性变化**与**造价**
- 配件冲突会自动禁用
- 边配边看花了多少钱、属性提升多少

### 七、热门信息

- 特勤处制作产物推荐
- 活动物品需求
- 高价格浮动制造材料前四
- 热门改枪码

### 八、战绩统计

**本周战绩**
- 收益、对局、出货记录汇总
- 今日 / 近 3 天 / 近 7 天 切换
- 总带出 / 净收益 / 对局数 / 撤离数 / 红卡数
- 出货列表可按**价格**或**时间**排序（再点反向）

**详情统计**
- 日历视图，按日查看**每一局**战绩
- 当天出的红 / 卡 / 金明细
- 数据逐步获取并缓存，不用每次重拉

### 九、其他

- **系统托盘常驻** — 关窗可选最小化到托盘，Overlay 继续给 OBS 用
- **开机自动启动** — 设置里一键开关
- **应用内自动更新** — 检测到新版本可直接下载安装，支持自动选最快下载源
- **手机端适配** — 浏览器打开同一地址，手机上也能查看全部数据

## 使用方式

### 便携版（推荐）

1. 到 [Releases](../../releases) 下载最新 `delta-force-overlay-*.exe`
2. 双击运行，**免安装**，单文件
3. 在软件里扫码登录 WeGame
4. OBS → 来源 → 浏览器 → 尺寸 `540 × 340` → URL 填 `http://127.0.0.1:8788/overlay`

### 局域网 / 手机访问

同一 WiFi 下，手机浏览器打开 `http://<电脑IP>:8788/` 即可查看所有数据。

## 常见问题

**Q：必须开着软件才能用 Overlay 吗？**
是。软件是本地数据服务，OBS 从它取数据。关掉浏览器窗口默认会退出软件；想要后台常驻，在设置里打开「关闭窗口时最小化到托盘」。

**Q：登录态会掉吗？**
软件每 30 分钟自动续期一次。如果超过 2 小时没续上，会在界面上提示重新扫码。注意**同一个 QQ 不要同时在多处登录**，会互相踢下线导致 cookie 失效。

**Q：数据会被上传吗？**
不会。所有请求从你的电脑直接发往 WeGame / 数据源，没有中间服务器。账号 cookie 只保存在本机数据目录。

**Q：杀毒软件报毒？**
单文件便携版 exe 解压运行，部分杀软会误报。源码公开构建，可自行核对。
